# CodeAlpha - Exploratory Data Analysis (EDA) Project

## Task 2: Exploratory Data Analysis (EDA)
This project performs an exploratory analysis on scraped book data to identify pricing trends and availability patterns.

## Analysis Steps
1. **Data Cleaning:** Processed price strings into numerical data type (float).
2. **Descriptive Statistics:** Calculated mean, min, and max book prices.
3. **Data Visualization:** Built distribution plots for prices and stock status using Seaborn and Matplotlib.

## Key Insights
- Cleaned and prepared raw scraped data for statistical operations.
- Identified price ranges and verified stock distribution across all items.

## Technologies Used
- Python (Pandas, Matplotlib, Seaborn)
